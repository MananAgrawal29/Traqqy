# Subscription Catalog Upgrade (Major Feature)

I want to completely redesign the subscription creation experience to make it feel like a professional SaaS application.

This is a feature update to the existing project.

## IMPORTANT

Do NOT rewrite the whole application.

Only improve and extend the existing codebase.

Keep the existing UI style and architecture.

Refactor only where necessary.

---

# Goal

The current app requires users to manually type the subscription name.

I DO NOT want that.

I want a built-in subscription catalog similar to Spotify, Apple Wallet or Google Pay.

The user should simply search and select a subscription.

# Multi Currency Support

Support all major world currencies.

At minimum support every common ISO-4217 currency.

Each currency should include

* Country flag
* Symbol
* ISO code
* Full currency name

🇺🇸 $ USD — US Dollar

🇬🇧 £ GBP — Pound Sterling

🇪🇺 € EUR — Euro

🇯🇵 ¥ JPY — Japanese Yen

Support automatic formatting.
